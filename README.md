# AI Python Kit

AI Python Kit is a planned toolkit for maintainers and coding agents who want consistent engineering quality in new and existing Python projects. It brings together project-owned policies, existing verification tools, portable Agent Skills, and review based on evidence.

**Status** · M0 specification. The v0.1.0 template, commands, skills, and acceptance suite are planned.

v0.1.0 will support project initialization, adoption, and updates with Copier. Composable profiles will guide engineering choices. The local and continuous integration (CI) workflow will run the same checks, and maintainers will retain authority over policy exceptions and acceptance.
